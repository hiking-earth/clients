# 徒步地球：自动同步与发布开发记录

这是开发检查点，尚未完成统一测试，也没有发布新版安装包。旧 APK 与旧桌面包不能证明本轮功能。

## 已写入代码

- 0.2.0 / versionCode 20：Android 更新清单、下载大小及 SHA-256 验证、系统安装器确认；iOS 仅连接正式签名的 App Store / TestFlight 入口；小程序使用微信 UpdateManager；桌面使用 Tauri 签名更新包。
- 桌面 updater 独立签名密钥保存在用户目录，GitHub Secret 已配置。它不替代 macOS 公证或 Windows 商业代码签名。
- 按统一账号选择开启自动同步，默认关闭。前台每分钟同步收藏、行程和已授权的完成轨迹；库冲突保留本机，账号变化和授权撤回中断后续写入；删除记录不会被自动同步复活。
- 云端日记、路线留言、队内消息、审核通知；公开日记默认关闭，公开内容经服务端管理员审核。网页本地原型界面改为同源共享客户端，原本机数据仍可导出。
- 官方路线审核管理页面、官方域名白名单和七天开放状态有效期；状态不能代替轨迹许可。缓存状态会重新应用到更新后的目录。
- NPS 官方 RSS 公告索引采集脚本与共享展示页面，实际采集111条。只保存标题、日期和官方链接，不复制文章正文及图片。
- 香港 AFCD 官方167条步道发现档案，保留 DATA.GOV.HK 来源与使用条款；约906 KB离线参考线包。参考线不是完整底图、高程或当天通行许可。
- OSM 四度小块历史回填脚本：区域轮转、密集块拆分、按源水位增量复查。解决旧大范围查询难以完成历史补录的问题。采集不等于功能测试。
- H5/桌面 OpenFreeMap 在线底图，用户主动选择显示；原生地图凭据入口及本机参考线回退。尚未运行或编译。
- H5、小程序共享构建流水线；桌面三平台草稿构建及签名 updater JSON；已发表且验收通过的版本才生成正式 Android 更新清单。
