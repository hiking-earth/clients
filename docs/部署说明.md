# 部署说明（动工后必读）

> 代码已全量完成，但要真正跑起来需要以下一次性配置（都需要用户本人的账号操作，AI 无法代办）。

## 1. 微信小程序（最先做）

1. 注册小程序（个人主体，类目选**运动户外**）→ 拿到 AppID
2. 填入 `app/src/manifest.json` → `mp-weixin.appid`
3. 开通**微信云开发**：微信开发者工具 → 云开发 → 创建环境，环境 id 填入 `shared/constants/index.ts` 的 `CLOUD_ENV`
4. 在云数据库建集合：`companion_posts` `teams` `team_members` `sos_events` `tracks` `guide_items`（权限：仅创建者可读写 / 按函数逻辑）
5. 部署云函数：开发者工具中 `app/cloudfunctions/` 下每个目录右键「上传并部署：云端安装依赖」（共 12 个）
6. 类目资质提醒：导航功能涉及测绘边界，上架审核时若被要求说明，强调"轨迹为参考示意，不提供测绘级导航服务"

## 2. 拍照识装备（视觉模型）

在云函数 `gear-scan` 的环境变量里配置（缺一即返回明确错误，不影响其他功能）：

| 变量 | 说明 | 示例 |
|---|---|---|
| `LLM_BASE_URL` | OpenAI 兼容接口地址 | `https://dashscope.aliyuncs.com/compatible-mode`（通义 qwen-vl）或 DeepSeek |
| `LLM_API_KEY` | 平台申请的 key | **严禁提交进代码库** |
| `LLM_MODEL` | 视觉模型名 | `qwen-vl-plus` / `glm-4v` 等 |

## 3. Android 未签名包（官网下载）

- uni-app 打 APK 需要 HBuilderX（可视化 → 发行 → 原生 App 云打包，选"公共测试证书"即未正式签名）
- 打出的 APK 挂到 hiking-earth 网页端下载页（网页仓库另提 PR）

## 4. Tauri 桌面端

```bash
cd desktop
npm install
npm run dev    # 开发预览（窗口加载网页端线上地址）
npm run build  # 产出 dmg / msi / appimage / deb
```
- `src-tauri/tauri.conf.json` 的 `app.windows.url` 即包裹的网页地址；网页更新桌面端自动跟进，无需发版
- crates 已配国内镜像（`~/.cargo/config.toml` rsproxy），首次编译约 1 分钟

## 5. H5 预览

```bash
cd app
npm run dev:h5       # 开发预览（H5 地图需腾讯地图 key，未配置时地图区显示占位，箭头导航不受影响）
npm run build:h5     # 产物在 app/dist/build/h5
```

## 6. 检测入口

```bash
# 导航核心算法单元测试（28 项）
node --experimental-strip-types shared/tests/navigation-core.test.mjs
# 类型检查
cd app && npm run type-check
# 桌面端编译验证
cd desktop/src-tauri && cargo check
```
