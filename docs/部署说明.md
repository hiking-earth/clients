## 1. 微信小程序（最先做，约 20 分钟）

> ⚠️ 用的是桌面端「**微信开发者工具**」，不是手机上的"小程序开发助手"——后者只能预览，不能开云开发。

### 1.1 注册小程序（网页操作，约 10 分钟）
1. 浏览器打开 **mp.weixin.qq.com** → 右上角「立即注册」
2. 账号类型选「**小程序**」
3. 填邮箱（没注册过公众号/小程序的邮箱）→ 设密码 → 去邮箱点激活链接
4. 主体类型选「**个人**」→ 填姓名、身份证号 → 用你的微信扫页面二维码完成管理员验证
5. 注册完成进入后台 → 左侧「设置」→「基本设置」→ 记下 **AppID**（wx 开头 18 位）
6. 左侧「开发」→「开发管理」→「开发设置」→ 同样在这是 AppID 位置
7. 类目：左侧「设置」→「基本设置」→「服务类目」→ 添加「**运动 > 运动户外**」（个人主体可过；若审核问导航，说明"轨迹为参考示意，非测绘级导航服务"）

### 1.2 填 AppID 到代码
- 编辑 `app/src/manifest.json` → `"mp-weixin"` → `"appid"` 填入你的 AppID → 重新构建：
  ```bash
  cd ~/Desktop/徒步软件/app
  npm run build:mp-weixin
  ```

### 1.3 开通云开发 + 部署（微信开发者工具内，约 10 分钟）
1. 下载安装**微信开发者工具**（developers.weixin.qq.com/miniprogram/dev/devtools/download.html，选 macOS 稳定版）
2. 打开工具 → 用你的微信扫码登录 → 左上角「+ 导入项目」→ 目录选 `~/Desktop/徒步软件/app/dist/build/mp-weixin` → AppID 填你的 → 导入
3. 工具顶部点「**云开发**」按钮 → 开通 → 创建环境（环境名建议 `hiking-earth-prod`）→ 记下**环境 ID**
4. 把环境 ID 填进 `shared/constants/index.ts` 的 `CLOUD_ENV`
5. 云开发控制台 → 「数据库」→ 新建 6 个集合（权限都选"仅创建者可读写"）：
   `companion_posts`、`teams`、`team_members`、`sos_events`、`tracks`、`guide_items`
6. 部署云函数（12 个）：在工具左侧文件树找到 `cloudfunctions` 目录（若没有，把 `app/cloudfunctions` 整个文件夹拖到工具的项目根，或在 project.config.json 里配 `"cloudfunctionRoot": "../../cloudfunctions/"` 后重导），**逐个右键** →「上传并部署：云端安装依赖（不上传 node_modules）」
7. 编译预览：首页应能看到 20 条路线；登录、约伴、组队、导购直接可用（装备识别需第 2 步的 LLM key）

### 1.4 真机预览与体验版
- 工具右上角「预览」→ 手机微信扫码即可真机跑（定位/罗盘在真机才有效）
- 想发给朋友：右上角「上传」→ 小程序后台「版本管理」→ 设为体验版 → 添加体验成员

## 2. 拍照识装备（视觉模型）

在云函数 `gear-scan` 的环境变量里配置（缺一即返回明确错误，不影响其他功能）：

| 变量 | 说明 | 示例 |
|---|---|---|
| `LLM_BASE_URL` | OpenAI 兼容接口地址 | `https://open.bigmodel.cn/api/paas/v4`（智谱） |
| `LLM_API_KEY` | 平台申请的 key | **严禁提交进代码库** |
| `LLM_MODEL` | 视觉模型名 | `glm-4v-flash` |

### 免费视觉模型推荐（2026-10 核实，全部国内直连、手机号注册、OpenAI 兼容，gear-scan 直接可用）

| 平台 | 免费模型 | 额度 | BASE_URL |
|---|---|---|---|
| **智谱（推荐首选）** | `glm-4v-flash` 完全免费；`glm-4.6v-flash`、`glm-4.1v-thinking-flash` 也免费 | 不限 token，限并发 1-10（高峰会 429，重试即可） | `https://open.bigmodel.cn/api/paas/v4` |
| 阿里百炼 | `qwen3-vl-flash` 等 Qwen-VL 系列限免 | 新用户每模型 100 万 token / 90 天 | `https://dashscope.aliyuncs.com/compatible-mode` |
| 硅基流动 | 指定免费模型（以控制台为准） | 注册送 2000 万 token | `https://api.siliconflow.cn/v1` |
| InternAI（上海 AI 实验室） | `internvl-latest` | 30 RPM，9000 万 token/月 | `https://chat.intern-ai.org.cn/api/v1` |

申请路径（以智谱为例）：open.bigmodel.cn 注册 → 控制台 → API keys → 新建 key → 填进云函数环境变量。

## 3. Android 未签名 APK（HBuilderX，约 15 分钟）

> APK 由 DCloud 云打包服务生成，**必须**用 HBuilderX 图形界面 + 你的 DCloud 账号，AI 无法代办。

1. 下载 **HBuilderX**（dcloud.io/hbuilderx.html，选"App 开发版"）→ 安装打开
2. 注册/登录 DCloud 账号（HBuilderX 右上角头像，手机号注册即可）
3. 菜单「文件」→「打开目录」→ 选 `~/Desktop/徒步软件/app`
4. 首次打开会提示安装 uni-app 编译插件，按提示装
5. 菜单「工具」→「插件安装」确认有 `uni-app (Vue3) 编译器`
6. 在 manifest 可视化编辑器里（双击 `src/manifest.json`）：
   - 基础配置：应用名称「徒步地球」、应用标识建议 `earth.hiking.app`
   - App 图标配置：选 `assets/icon-512.png`，点"自动生成所有图标"
   - App 权限配置：勾选 Geolocation、Maps
7. 菜单「发行」→「**原生 App-云打包**」：
   - 平台选 **Android**（iOS 无开发者账号打不了）
   - 证书选「**使用公共测试证书**」（= 未正式签名，官网分发够用）
   - 广告全不勾 → 点「打包」
8. 等 5-10 分钟（云端排队），控制台出 APK 下载链接 → 下载
9. 把 APK 上传到 `hiking-earth/clients` 的 Release（和 dmg 一样 `gh release upload`），或挂到 hiking-earth 网页端下载区
10. 手机安装时会提示"未知来源"，允许即可；MIUI/EMUI 可能要多点一次"仍要安装"

> iOS 说明：未签名包 iPhone 装不了（系统限制），要真机上架/TestFlight 必须注册 Apple 开发者账号（$99/年，developer.apple.com），M5 再定。
