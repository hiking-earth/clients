# 统一微信、手机号登录与虚拟验收框架

状态：用户已授权需求，尚未实现及验收。

## 身份与登录
- 内部统一userId为业务归属；微信appid/openid、可用的UnionID、已验证手机号作为外部身份映射，客户端填写的号码不作为认证证据。
- 小程序保留微信一键登录；登录不自动获得手机号。另行由用户主动授权获取手机号，服务端使用微信官方接口校验短期code，不信任客户端号码。
- 网页/桌面先实现小程序确认式扫码：短期随机一次性挑战；扫码端登录后显示设备和授权范围，主动确认；浏览器以独立随机领取凭据取得会话，二维码不是会话token。过期/取消/领取后不可复用，限流并绑定发起端。
- 微信开放平台网站应用OAuth作为另一个适配器，必须核实资格和配置，不冒充已获官方网站登录授权。
- 手机号登录采用真实验证码服务适配器，限流、验证码短期一次性且不可日志输出。生产环境缺失免费可用服务时禁用发送，模拟验证码仅隔离测试。
- 同一经过认证的微信身份关联到统一账号。相同已验证手机号仅在不存在冲突时建立登录方式关联；两个已有数据账号、管理员/组织权限、回收号码等冲突需两边认证及显式合并确认，不自动覆盖数据或继承权限。
- 不声称可以查询微信账号当前绑定手机号：只有用户授权提供的手机号证据或受支持UnionID可用。

## 自动验收
- Android Emulator：安装、UI、权限撤回、网络故障、GPS路线回放、进程恢复。
- Xcode Simulator：iOS模拟器构建/UI/模拟定位；PWA另用WebKit验证。原生模拟器产物不是iPhone IPA。
- 微信开发者工具：页面及接口自动化、小程序扫码协议；真实微信授权手机号需要正式平台配置和最后真机确认。
- 云真机：仅免费额度、不开付费项目。Firebase Test Lab有免费配额但存在平台迁移，接入时再次核对可用性。
- 真机保留项：真实授权、锁屏/后台定位、耗电、硬件定位表现、实际系统安装升级。
