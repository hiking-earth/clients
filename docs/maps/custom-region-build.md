# 按位置生成离线地区包

工作流 `offline-map-build.yml` 的手动运行支持 `custom_latitude`、`custom_longitude`、`custom_radius_km`、`custom_name`。经纬度均留空时继续构建预置目录；仅填写一个坐标会校验失败。

自定义区域半径为 1–10 公里，跨日期变更线自动拆分，高纬区域按生成器支持的大小分块。Mercator 极区不覆盖，越界请求明确拒绝。

所有分块使用同一上游快照，逐包校验、记录大小、SHA 和许可。完整批次导出 `catalog.json`；失败批次保留检查点和日志。结果保留于工作流产物 14 天，不能作为永久公开下载地址。自定义区域不会提交到应用内置目录，避免每次请求增加安装包体积。

当前边界：此入口供开发端手动生成；尚未接入用户自助请求、永久下载分发和跨端客户端目录。工作流本轮只完成本地 YAML 检查，未云端执行。底图不提供高程、路线开放核验或完整导航。

自定义批次另导出 `distribution/`：其中 `catalog.json` 使用客户端既有目录格式，`source-inventory.json` 保存生成来源，包文件复制后再次验证 SHA。发布时必须将该目录挂载到选定下载根的 `static/offline-maps/`，并提供 HTTPS。导出器拒绝覆盖既有目录，损坏来源不创建分发目录；复制失败不留下可发布目录标记。此导出尚未部署为公开端点，也未与客户端主目录合并。
